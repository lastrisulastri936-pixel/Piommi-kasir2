Backup & pemulihan data

Data disimpan otomatis di browser dan dibuat salinan pemulihan lokal setiap kali ada perubahan. Tetap unduh backup JSON ke perangkat/Drive secara berkala; salinan lokal ikut hilang jika data situs dihapus.

Catatan penggunaan

  • Aplikasi ini berjalan lokal di browser dan tidak memerlukan internet setelah file dibuka.
  • Data tidak otomatis tersinkron ke perangkat lain. Gunakan backup JSON.
  • Untuk keamanan, jangan gunakan mode incognito/private browsing.
  • Nomor WhatsApp toko dan biaya tetap bulanan dapat diatur di atas.
  • Invoice WhatsApp membuka chat berisi pesan siap kirim; kasir tetap perlu menekan tombol Kirim di WhatsApp. Pengiriman otomatis tanpa klik memerlukan WhatsApp Business Platform/API dan server.
  • Member otomatis tercatat saat transaksi memakai nomor WhatsApp; poin: 1 poin per Rp10.000 belanja.
  • Untuk multi-kasir dan sinkronisasi online diperlukan server dan database pusat.
